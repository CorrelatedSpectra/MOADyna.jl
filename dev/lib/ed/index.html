MOADyna.ED — Module
MOADyna.ED

Exact diagonalization for sparse and matrix-free operators.

Thin wrappers around KrylovKit.eigsolve and dense LAPACK extend LinearAlgebra.eigen. See the Exact diagonalization chapter of the manual for the user-facing contract.

This is an internal submodule of MOADyna; the names below are re-exported from the umbrella package, so users typically write using MOADyna and call eigen(H, basis) directly.

MOADyna.ED.ConvergenceError — Type
ConvergenceError <: Exception

Thrown when eigen(...) on the Krylov path doesn't converge to the requested number of eigenpairs.

Fields

  • converged::Int — number of eigenpairs that did converge
  • normres::Vector{Float64} — per-eigenpair residual norms; independently measured when the final check fails, otherwise reported by KrylovKit
  • info — original KrylovKit ConvergenceInfo for diagnostics

Use max_normres for the worst-case scalar diagnostic.

MOADyna.ED.Eigenstates — Type
Eigenstates

Eigenstates returned by eigen(H, hilbert; restrictions, ...). values and vectors expose the usual eigenvalues and eigenvectors; vector rows refer to basis. backend records the operator representation. selection contains SelectedEigen diagnostics for an adaptive solve and is nothing otherwise. eigen gives the underlying LinearAlgebra.Eigen.

source
MOADyna.ED.SelectedEigen — Type
SelectedEigen

Eigenstates on a selected basis. eigen.vectors uses the coordinates of basis. residuals contains full allowed-space residual norms, including omitted states; residual_norm is their Euclidean norm, equivalently the block Frobenius norm. iterations counts outer iterations and candidate_count counts nonzero external rows in the last residual check (nothing if that check was incomplete). Full-space Hermiticity is assumed; each projected Hamiltonian is checked by eigen.

MOADyna.ED.save_eigensystem — Method
save_eigensystem(file::AbstractString, sys; basis_id = nothing)

Save eigenvalues + eigenvectors to an HDF5 file. The sparse Hamiltonian is intentionally NOT saved; rebuild it via assemble(compile(H, basis), basis) when required.

sys must expose sys.values (convertible to Float64) and sys.vectors (convertible to ComplexF64); a LinearAlgebra.Eigen returned by eigen(H, basis) qualifies. The optional basis_id keyword is written under /basis_id if provided (typically the UInt64 token returned by MOADyna.Bases.basis_id(basis), but a String is also accepted).

Round-trips with load_eigensystem.

MOADyna.ED.selected_eigen — Method
selected_eigen(H, seed; restrictions, max_states, residual_tol=1e-8,
               n=1, backend=:matrixfree, kwargs...) -> SelectedEigen

Converge low-energy eigenstates without enumerating the full allowed basis. seed is a small basis on the same Hilbert space. The required restrictions keyword defines the allowed physical space (nothing permits all states); restrictions used to construct the seed are not implicitly retained.

Each iteration solves an exact, fixed selected-space problem, evaluates H*Ψ-Ψ*Diagonal(E) including omitted states, and adds determinants ranked by their residual row norms. Already selected states are retained. residual_tol bounds the full block Frobenius norm, and therefore every normalized linear combination of the returned states. The lowest n states of the selected problem are requested, including any projected degenerate cluster crossing that boundary (degen_tol=1e-8). Residual convergence alone cannot certify the multiplicity of the full allowed-space spectrum. Each enlarged basis starts with at most n provisional states. Once their full residual passes, the boundary cluster is completed progressively and every added member is checked before acceptance.

max_states caps the retained basis. max_candidates=max_states caps unique generated external states before all cancellations are resolved. Each discovery worker holds a single-column and a target-block accumulator, each capped at max_candidates, in addition to the final merge and output storage. Temporary storage consequently grows with the thread count. Exceeding either limit or maxiter=50 raises SelectionConvergenceError with the latest result. An inner Krylov failure raises ConvergenceError with that projected solve's diagnostics.

backend may be :matrixfree or :sparse. Inner solves reuse the previous eigenvector block. tol=nothing allocates half the squared residual budget to the inner solve; an explicit tol overrides that choice. eig_maxiter=300, krylovdim=20, dense_below=1024, and threaded=:auto control the same kernels as eigen. The dense threshold applies only to the sparse backend.

The Hamiltonian must be Hermitian throughout the allowed space. A small residual certifies approximate eigenstates, not discovery of the global ground state or all degenerate partners. Unseeded disconnected sectors are unreachable. Provisional search can also leave some directions of a degenerate seed unexplored; use physically appropriate seeds and check stability under their enlargement. Ground-state convergence alone does not certify a spectrum; transition and response spaces require their own convergence checks.
