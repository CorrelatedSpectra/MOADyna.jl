Hilbert Spaces & Bases

MOADyna.Bases turns the symbolic Operator Algebra into numbers. It assembles named sites into a Hilbert space and enumerates a conserved sector with basis. A symbolic OperatorSum can then be assembled as a sparse matrix with compile / assemble, or applied without storing matrix elements using matrixfree.

Hilbert spaces

A Hilbert collects sites under their names; the tensor product ⊗ and the name => site constructor both build one.

using MOADyna

sites = [FermionSite{2}(Symbol("s$i")) for i in 1:4]
h = Hilbert(s.name => s for s in sites)
h isa Hilbert
true

Conserved-sector restrictions

Enumerating the full Fock space is exponential and almost never needed: physical Hamiltonians conserve particle number, Sz, etc., so work in one sector. A QuantumNumber (n_fermion, Sz_total, WeightedParticleCount) compared with == (or ∈ a range) yields a Restriction. basis enumerates exactly the states satisfying all restrictions.

sz_w  = repeat([1, -1], 4)                         # +1 on ↑, −1 on ↓
b = basis(h,
                   n_fermion(h) == 4,              # half-filling
                   WeightedParticleCount(sites, sz_w) == 0)   # Sz = 0
length(b)
36

EagerBasis materializes the sector's state list eagerly (the bit-packed Fock states), so get_state / get_index map between states and indices in $O(1)$–$O(\log n)$.

Compile and assemble

compile resolves a symbolic operator against a basis (matching its sites and modes to their bit positions, and expanding Sx/Sy into S+/S−); assemble then builds the SparseMatrixCSC. Splitting the two lets you compile several operators (the Hamiltonian, observables, …) against one shared basis and assemble each separately, and supports the parallel sparse-assembly path.

H  = -1.0 * sum(add_hc(cdag(sites[i], σ) * c(sites[i+1], σ)) for i in 1:3, σ in 1:2)
Hc = compile(H, b)
Hs = assemble(Hc, b)
size(Hs)
(36, 36)

Matrix-free actions

matrixfree retains compiled operator terms and determinant lookup tables, and generates matrix elements during multiplication. It supports vectors, blocks of vectors, mul!, adjoints and the same fixed-basis solvers as sparse storage.

A = matrixfree(H, b; threaded=false)
v = ones(length(b))
A * v ≈ Hs * v
true

This construction keeps every state in b and applies the projected operator exactly, up to floating-point arithmetic. Keep the basis data unchanged while using the action. threaded=:auto uses the available Julia threads; true and false explicitly select parallel or serial products. sparse(A) and Matrix(A) are explicit conversions when stored matrix elements are needed.

Matrix-free storage is useful when the Hamiltonian's nonzero entries dominate memory. The basis and solver vectors are still stored explicitly; generating matrix elements at each multiplication can cost more time than sparse products. See Matrix-free Calculations for a worked example and selected-basis options.

For transitions between different sectors, use matrixfree(T, bra, ket). Its output coordinates belong to bra and input coordinates to ket; both bases must use the same site and mode encoding. The adjoint reverses these roles.

Embedding between sectors

embed lifts a vector from one basis into a larger one (e.g. a ground state into the bigger basis a core-hole spectrum lives in) — the mechanism the spectroscopy wrappers use to connect the initial- and final-state sectors. apply_restriction! projects a vector into a sector in place (used by the restriction-resolved partial-spectrum path).
