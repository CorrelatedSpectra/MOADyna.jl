Spectroscopy

MOADyna.Spectroscopy turns a sparse or matrix-free Hamiltonian and a ground (or thermal) state into a frequency-resolved spectrum. It covers two families:

  • Core-level spectroscopy — xas (X-ray absorption), rixs (resonant inelastic X-ray scattering), fluorescence_yield. These use the transition operators from the Multiplets & Standard Operators chapter.
  • Response functions — optical_conductivity (regular $\operatorname{Re}\sigma_{\alpha\beta}(\omega>0)$) and dynamical_structure_factor ($S(\mathbf{q},\omega)$, including the nIXS spectrum). These are thin one-sided wrappers over correlator with bring-your-own operators.

Every entry point returns a SpectraTensor: a tensor of spectra over an ω grid, with HDF5 round-trip and a shared broadening convention (Lorentzian FWHM Γ) and unified scalar frequency $z = \omega + E_g + i\Gamma/2$ and resolvent $(zI - H)^{-1}$ (see the Conventions appendix). The Lanczos-backed core-level spectra (XAS/RIXS/FY) additionally carry the block-Lanczos chunks, so they can be re-broadened and polarization-sliced without recomputing (re_broaden_table); the response wrappers (optical_conductivity, dynamical_structure_factor) return an already-evaluated algebraic tensor (chunks = nothing), so re_broaden_table does not apply to them — re-run with a new Γ instead.

Spectroscopy from eigenstates

Pass a symbolic Hamiltonian and physical restrictions to eigen to keep the solved states together with their basis. The spectroscopy functions can then construct their own sectors and transitions automatically:

gs = eigen(H_GS, m; restrictions=initial_sector, n=1)
T = dipole(m, :Ni_2p => :Ni_3d)
spec = xas(H_XAS, T, gs; restrictions=core_hole_sector,
           omega_grid=incident_grid, Gamma=0.6)
result = rixs(H_final, H_XAS, T, T, gs;
              restrictions_intermediate=core_hole_sector,
              restrictions_final=final_sector,
              omega_in_grid=incident_grid, omega_out_grid=loss_grid,
              Gamma_intermediate=0.6, Gamma_final=0.1)

Here m is a ShellModel (a Hilbert also works), and each sector is a restriction or collection of restrictions on individual determinants. The initial and core-hole occupations must be specified separately. The default is sparse storage; backend=:matrixfree can be selected in the solve or overridden in a spectrum call. The same result supports finite-temperature keywords when enough initial eigenstates have been computed.

Each call enumerates the response sectors specified by its restrictions and constructs transitions from the initial-state basis. For fluorescence yield, restrictions_final defines the decay destinations. Response basis selection and its convergence controls are provided by selected_response.

Use the explicit interfaces below to reuse bases and prepared actions across calculations.

X-ray absorption (XAS)

XAS evaluates $I(\omega) = -\tfrac{1}{\pi}\operatorname{Im}\langle g|T^\dagger (\omega + E_g - H + i\Gamma/2)^{-1} T|g\rangle$ for a transition operator T (a Cartesian dipole component) acting on the ground state $|g\rangle$. The Hamiltonian H is the final-state Hamiltonian (with the core hole); $|g\rangle$ is the initial ground state embedded into the final-state basis.

# (Illustrative — the full runnable workflow is examples/05_nio_xas.jl and the
#  NiO tutorial. T = dipole(m, :Ni_2p => :Ni_3d) is built in the Multiplets chapter.)
gs   = eigen(H_GS, basis_gs; n = 1)
psi0 = embed(gs.vectors[:, 1], basis_gs => basis_xas)
H_xas = assemble(compile(H_XAS, basis_xas), basis_xas)

T = dipole(m, :Ni_2p => :Ni_3d)          # the full Cartesian vector [T_x, T_y, T_z]
spec = xas(H_xas, basis_xas, T, psi0;    # ⇒ polarisation tensor χ_ab(ω), shape (3, 3, n_ω)
           omega_grid = range(-15, 25; length = 801),
           Gamma      = 0.6,
           Eg         = gs.values[1])

Pass a single operator (e.g. Tz) and spec.tensor is the scalar complex response (-imag of it is the absorption). Pass the whole vector T and xas returns the full polarisation tensor $\chi_{ab}(\omega)$. Any polarisation then follows from one contraction with polarise: for a unit Jones vector $\boldsymbol\varepsilon$, $I(\omega) = -\operatorname{Im}\sum_{ab}\varepsilon_a^{*}\chi_{ab}(\omega)\varepsilon_b$.

polarise(spec, [0, 0, 1])               # linear ∥ z
polarise(spec, [1, im, 0] / sqrt(2))    # circular (right) → XMCD against its conjugate
polarise(spec)                          # for a scalar-T result: just −Im(tensor)

Linear dichroism is two real $\boldsymbol\varepsilon$; XMCD is the difference of the two circular helicities; the isotropic spectrum is the average over any three orthogonal $\boldsymbol\varepsilon$ (equivalently $\tfrac13\operatorname{tr}\chi$). The NiO tutorial works a full magnetic-linear-dichroism (XMLD) example end to end.

Resonant inelastic X-ray scattering (RIXS)

RIXS is the two-step coherent process: excite with T_in, propagate in the intermediate (core-hole) Hamiltonian, de-excite with T_out, and resolve in both incident and energy-loss axes. rixs takes the final- and intermediate-state Hamiltonians separately.

# (Illustrative — full runnable workflow: examples/06_nio_rixs.jl.)
result = rixs(H_final, H_intermediate, basis, T_in, T_out, psi0;
              omega_in_grid      = incident_grid,
              omega_out_grid     = loss_grid,
              Gamma_intermediate = 0.6,
              Gamma_final        = 0.1,
              Eg                 = Eg)

Scalar T_in/T_out give a single $(\omega_\mathrm{in}, \omega_\mathrm{out})$ map. Pass Cartesian vectors for both and rixs returns the four-index Kramers–Heisenberg tensor $\chi_{ijkl}$; polarise(result, ε_in, ε_out) contracts it for any incoming / outgoing polarisation pair, $\sigma = -\operatorname{Im}\sum_{ijkl}\varepsilon^{*}_{\mathrm{in},i}\varepsilon_{\mathrm{out},j}\chi_{ijkl}\varepsilon^{*}_{\mathrm{out},k}\varepsilon_{\mathrm{in},l}$ — so parallel vs crossed linear channels, or any circular combination, come from one calculation. The NiO tutorial works a polarisation-resolved RIXS example.

fluorescence_yield (fluorescence_yield(H_i, basis, T_excite, T_decay, ψ; …)) gives the integrated decay intensity used for partial-fluorescence-yield detection.

Matrix-free operators and separate sectors

Pass matrixfree(H, b) as the Hamiltonian to use matrix-free propagation. Symbolic transitions on the shared basis use the same backend. Alternatively, pass prebuilt sparse matrices or matrix-free transition actions; these can be reused across calculations.

The basis and solver vectors remain explicit. Choose this backend when avoiding matrix storage is useful; sparse propagation can be faster when the matrix fits. See Matrix-free Calculations for a runnable introduction.

Rectangular transitions connect distinct initial and propagation bases directly:

H_int = matrixfree(H_intermediate, basis_int)
T_actions = [matrixfree(t, basis_int, basis_gs) for t in T]
spec = xas(H_int, basis_int, T_actions, gs;
           omega_grid=incident_grid, Gamma=0.6)

Here gs is an Eigen on basis_gs. For RIXS, provide the final basis as the positional argument and set intermediate_basis=basis_int:

H_fin = matrixfree(H_final, basis_final)
incoming = [matrixfree(t, basis_int, basis_gs) for t in T_in]
outgoing = [matrixfree(t, basis_int, basis_final) for t in T_out]
result = rixs(H_fin, H_int, basis_final, incoming, outgoing, gs;
              intermediate_basis=basis_int,
              omega_in_grid=incident_grid, omega_out_grid=loss_grid,
              Gamma_intermediate=0.6, Gamma_final=0.1)

Both transition sets use the absorption orientation; RIXS applies the adjoint of each outgoing action. Use the same basis objects when constructing operators and calling the solvers. Matrix-free actions carry basis identities that are checked where available; for ordinary matrices and bare vectors, the caller must ensure the coordinate ordering agrees. Tensor shapes and polarization contraction are the same for both backends.

Response functions: optical conductivity and dynamical structure factor

The response wrappers are statistics-agnostic and operator-agnostic — you supply the operator. dynamical_structure_factor returns $S(\mathbf{q},\omega) = -\operatorname{Im} C(\mathbf{q},\omega)/\pi$ over the full ω grid for a momentum-resolved operator O_q; the nIXS spectrum is exactly this with O_q = nixs(…). The example below is small enough to run at build time.

using MOADyna

# 2-site, 2-orbital Hubbard dimer.
s = [FermionSite{2}(:a), FermionSite{2}(:b)]
h = Hilbert(x.name => x for x in s)
t, U = 1.0, 4.0
H = -t * sum(c'(s[1], σ) * c(s[2], σ) + c'(s[2], σ) * c(s[1], σ) for σ in 1:2) +
     U * sum(n(s[i], 1) * n(s[i], 2) for i in 1:2)

b   = basis(h, n_fermion(h) == 2)
Hsp = assemble(compile(H, b), b)
gs  = eigen(Hsp, b; n = 1)

# Staggered (q = π) charge operator as the probe.
O_q = (n(s[1], 1) + n(s[1], 2)) - (n(s[2], 1) + n(s[2], 2))

S = dynamical_structure_factor(Hsp, b, O_q;
                               omega_grid = range(0.0, 8.0; length = 200),
                               Gamma      = 0.3,
                               ψ₀         = gs.vectors[:, 1],
                               Eg         = gs.values[1])
(ndims(S.tensor), round(maximum(S.tensor); digits = 4))
(1, 1.2421)

Results are SpectraTensors, and the post-processing toolkit combines them: average and weighted_sum build ensembles (orientational, thermal, configurational), restrict_to_window crops the ω axis, and save_spectra/load_spectra round-trip to HDF5:

O_spin = (n(s[1], 1) - n(s[1], 2)) - (n(s[2], 1) - n(s[2], 2))   # a second probe
S_spin = dynamical_structure_factor(Hsp, b, O_spin;
                                    omega_grid = range(0.0, 8.0; length = 200),
                                    Gamma = 0.3, ψ₀ = gs.vectors[:, 1], Eg = gs.values[1])
S_avg = average([S, S_spin])                    # equal-weight ensemble
S_w   = weighted_sum([S, S_spin], [0.7, 0.3])   # arbitrary weights
(round(maximum(S_avg.tensor); digits = 4), round(maximum(S_w.tensor); digits = 4))
(3.5838, 2.151)

optical_conductivity returns the regular part $\operatorname{Re}\sigma_{\alpha\beta}(\omega>0) = (1 - e^{-\omega/T})\,\dfrac{-\operatorname{Im}\Lambda_{\alpha\beta}}{\omega V}$ from a bring-your-own current operator j (the Drude / diamagnetic weight is not included). Both wrappers take the finite-T path via T=… (thermal average over the low-lying states); see Responses for the underlying correlator.

Threading in spectroscopy

xas, rixs, and fluorescence_yield accept threaded=:auto (the default), threaded=true, or threaded=false. This controls Hamiltonian products and supported block full reorthogonalization, including nested recursions and thermal averages. Automatic mode uses workers for sufficiently large sparse products, preserves the threading choice of matrix-free actions, and applies a conservative per-block work floor to reorthogonalization. true requests these row kernels on the available default pool (possibly one worker); false keeps both serial. The two ordered projection passes over stored blocks are preserved, although row partitioning can change floating-point summation. Unsupported/wider arithmetic retains the serial path; the scalar-specialized recurrence retains its existing reorthogonalization.

optical_conductivity and dynamical_structure_factor forward the same control to their underlying response calculation. kubo_response applies it to sparse products in a partial eigensolve; its full dense eigensolve and eigenstate-pair sum retain their existing execution paths.

spec = xas(H_xas, basis_xas, T, psi0; Eg, threaded = false)
result = rixs(H_final, H_intermediate, basis, T_in, T_out, psi0;
              Eg, threaded = true)

Start Julia with, for example, --threads=4 to provide four workers. This setting is separate from basis/assembly scheduling and BLAS thread counts; it does not create additional Julia threads. A calculation prepares the sparse action once and reuses it across incident energies or initial states. Keep its Hamiltonians fixed until the calculation returns. See Multiplication threads in the ED manual for the solver setting.

Restriction-resolved partial excitations

To decompose a spectrum into final-state channels (e.g. the $d^9$ vs $d^{10}\underline{L}$ contributions of a charge-transfer system, or $t_{2g}$/$e_g$ channels), pass a restrictions predicate to xas/rixs: the Lanczos recursion applies it after every matvec, projecting the propagated state into the chosen sector — an in-recursion projection of the final-state dynamics, not a post-hoc filter of the result. The partials sum to the total only when the restriction is a conserved sector of H (otherwise restricting cuts the inter-sector coupling — a physical, documented caveat). The NiO tutorial works this end to end (the final-state nshells(m, :Ni_3d) == 9 channel of the L-edge).

Finite temperature

The neutral same-sector response wrappers — optical_conductivity and dynamical_structure_factor — accept a T keyword (with k_B = 1; not to be confused with the transition-operator argument T of the core-level functions). It replaces the single ground-state expectation by a Boltzmann-weighted sum over the low-lying eigenstates (degeneracy-complete truncation). The thermal machinery lives in correlator and is described in the Responses chapter.

For XAS, RIXS, and fluorescence yield, pass an eigensystem as the initial-state argument and set temperature=… (also with k_B = 1). Supply explicit frequency grids so the spectra from each initial state are evaluated on common axes before Boltzmann averaging. N_states and degen_tol control the retained ensemble; threaded has the same meaning as for a single initial state. The eigensystem's vectors must live in the propagation basis; use embed when the initial basis differs. Thermal averaging returns a grid tensor without retained Lanczos chunks, so re-broadening requires another calculation.
